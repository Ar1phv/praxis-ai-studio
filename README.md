# Praxis Execution Hub

Build the frontend MVP for Praxis.



Product:

Praxis is an autonomous product execution platform.



Tagline:

Execution, automated.



Core idea:

Users describe a product they want to build. Praxis coordinates specialized AI agents to plan, design, build, test, and ship the product.



Use the uploaded design as the primary visual reference. Match the layout, spacing, typography, and overall design language closely.



Product requirements:



1. Landing page



- Clear hero section

- Explain Praxis in one sentence

- Strong CTA: "Start an Execution"

- Show how Praxis transforms ideas into products



2. Execution Dashboard

   Create the main workspace where users manage projects called "Executions."



Include:



- Active execution status

- Progress timeline

- Agent activity feed

- Current tasks

- Completed tasks

- Blockers

- Deliverables



3. Agent System UI

   Create cards for AI agents:



- Orchestrator

- Product Agent

- Builder Agent

- Designer Agent

- QA Agent



Each agent should show:



- Status

- Current task

- Output generated



4. Project Creation Flow

   Create a simple onboarding experience:



User enters:

"What do you want to build?"



Example:

"Build a decentralized exchange on Injective."



Praxis creates:



- Product plan

- Technical architecture

- Execution roadmap



5. Design direction:



- Premium AI startup aesthetic

- Minimal

- Dark interface

- High contrast

- Clean typography

- Professional enterprise feel

- Avoid generic chatbot styling



6. Technical requirements:



- Build using React

- Use reusable components

- Keep the codebase clean and scalable

- Prepare the frontend for future API integration

- Use mock data for now



Do not build fake AI functionality. Focus on creating the product experience and interface.

The goal is to create the foundation of a world-class autonomous execution platform.

Strictly follow attached brand design
